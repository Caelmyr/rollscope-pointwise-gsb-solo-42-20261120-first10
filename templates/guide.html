Capture format

Open a NumPy NPZ containing the scan, encoder positions, acquisition times, and independent flat-field references. Download the synthetic capture from the library as a working example.

MemberShape and scalar typeMeaning
raw8–4096 × 16–1024 integersSensor codes 0–65535, scan lines in arrival order
ticksOne integer per lineNondecreasing encoder tick, including multiple scans at the same tick
secondsOne number per lineStrictly increasing time in seconds, at least 1 ns apart
dark, white1–64 passes × raw columns eachStart-of-roll dark and white reference sensor codes in the same detector columns
dark_end, white_endOptional, same shapes as dark/whiteEnd-of-roll references. Both must be present together; the app then transitions column-by-column from the start set to the end set along scan station
reference_secondsOptional, one number per reference event (1 or 2)Capture times of the reference events; increasing in event order. Defaults to the first/last scan times when omitted
metadata_utf81D uint8UTF-8 JSON carrying capture metadata and physical geometry

Metadata example

{
  "name": "Coil R24-071 / side A",
  "material": "Cold-rolled steel",
  "description": "Synthetic demonstration",
  "synthetic": true,
  "geometry": {
    "tick_mm": 0.18,
    "column_mm": 0.28,
    "station_origin_mm": 1200,
    "transverse_origin_mm": 0
  }
}

Station is origin plus tick × pitch. Transverse position is origin plus a zero-based column × pitch. Reflection values are dimensionless relative to the dark and white references. The preview applies display scaling; the probe and evidence retain measured values.

Timed start and end references

Bundles with only dark and white open exactly as before and apply that single reference set to every scan line. When dark_end and white_end are supplied, each detector column is checked independently at both reference events and the effective dark/white level transitions linearly from the start event to the end event along the scan station. A column rejected at one event still produces evidence near the other event, up to the configurable single-reference trust reach (a fraction of the roll length); beyond that reach the cell is marked unknown rather than extrapolated. Columns rejected at both events, or saturated scan pixels, stay unknown across the whole capture. The probe reports the reference basis (start, end, blended or unknown), the weight taken from each event, their recorded times, and the contributing raw scan lines. Evidence NPZ exports carry the same basis and transition arrays and the settings JSON that produced them, so a downloaded source can be re-opened with identical settings.

Review workflow

  1. Open the raw scan and check acquisition events. Use Coverage to see gaps and rejected detector columns separately.
  2. Use Strip geometry or a surface analysis. Choose Settings to adjust the analysis and save a report before exploring different values.
  3. Click an image cell to see contributing source lines. Use Review windows for a saved physical interval or Ruler for a two-point measurement.
  4. Export ZIP evidence from the current analysis, window, ruler, or saved report. Back up and restore the whole inspection from the capture library.

The library accepts up to 64 captures and up to 512 MiB of source data. The uniform station grid is capped at 3,000,000 cells. These measurements are intended for exploratory inspection.
